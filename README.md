# HotSwap

HotSwap is a lightweight, client-side Minecraft mod that automatically selects the optimal tool or weapon in your hotbar 
based on what you’re doing. By leveraging Minecraft’s built-in item tags, HotSwap ensures you always have the right tool 
in hand without manual inventory juggling.
